# ArgusAI — Mac 5 AM Scheduler Setup Guide
## MTM Logix | Claude in Chrome → LinkedIn → ClickUp

This guide sets up your Mac to automatically open Chrome to Lars Jensen's
LinkedIn feed every morning at 5:00 AM, so Claude in Chrome can run the
ArgusAI intelligence routine and push updates to ClickUp.

---

## WHAT YOU'LL NEED
- Mac with Google Chrome installed
- Claude in Chrome extension installed and connected
- ~15 minutes for setup

---

## STEP 1 — Find Your Mac Username

Open Terminal (Cmd+Space → type "Terminal" → Enter) and run:
```
whoami
```
Write down the result — this is your YOURUSERNAME.
Example: `marioveraldo`

---

## STEP 2 — Copy the Shell Script to Your Home Folder

In Terminal, run these commands one at a time:

```bash
# Copy the script to your home folder
cp ~/Downloads/argusai_daily_run.sh ~/argusai_daily_run.sh

# Make it executable
chmod +x ~/argusai_daily_run.sh
```

---

## STEP 3 — Edit the Plist File (Replace YOURUSERNAME)

Open the plist file in TextEdit:
```bash
open -e ~/Downloads/com.mtmlogix.argusai.dailyrun.plist
```

Find ALL instances of `YOURUSERNAME` and replace with your actual username.

Example — change:
  `/Users/YOURUSERNAME/argusai_daily_run.sh`
To:
  `/Users/marioveraldo/argusai_daily_run.sh`

Do the same for the two log file paths. Save and close the file.

---

## STEP 4 — Install the LaunchAgent

In Terminal:
```bash
# Copy the plist to the LaunchAgents folder
cp ~/Downloads/com.mtmlogix.argusai.dailyrun.plist ~/Library/LaunchAgents/

# Load it so it becomes active immediately
launchctl load ~/Library/LaunchAgents/com.mtmlogix.argusai.dailyrun.plist
```

Verify it loaded:
```bash
launchctl list | grep argusai
```
You should see: `com.mtmlogix.argusai.dailyrun`

---

## STEP 5 — Test It Right Now (Optional but Recommended)

Run the script manually to make sure it works:
```bash
bash ~/argusai_daily_run.sh
```

Chrome should open to Lars Jensen's LinkedIn feed and the Claude in
Chrome panel should open automatically.

---

## STEP 6 — Grant Accessibility Permissions (One-Time)

The script uses AppleScript to control Chrome. Mac will ask for permission
the first time:

1. Go to: Apple Menu → System Settings → Privacy & Security → Accessibility
2. Make sure "Terminal" (and/or "Google Chrome") has the toggle ON
3. If prompted, click "Allow"

---

## TROUBLESHOOTING

**Script doesn't run at 5 AM?**
```bash
# Check if the LaunchAgent is loaded
launchctl list | grep argusai

# Reload it
launchctl unload ~/Library/LaunchAgents/com.mtmlogix.argusai.dailyrun.plist
launchctl load ~/Library/LaunchAgents/com.mtmlogix.argusai.dailyrun.plist
```

**Mac needs to be awake at 5 AM:**
- Go to System Settings → Battery → Schedule
- Set "Wake for network access" or schedule a wake time at 4:55 AM

**Check the log:**
```bash
cat ~/argusai_daily_run.log
```
